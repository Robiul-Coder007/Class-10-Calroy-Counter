# Calorie Counter

A Django-based web application for calculating estimated daily calorie requirements and tracking daily calorie intake.

## Features

- User registration
- Username login
- Email login
- User profile management
- Male and Female BMR calculation
- Daily calorie tracking
- Dashboard
- Daily consumed calorie summary
- Remaining calorie calculation
- Calorie item deletion
- Password change
- Django admin panel
- Automated tests

## Technologies

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap

## BMR Formula

### Male

BMR = 66.47 + (13.75 × weight) + (5.003 × height) − (6.755 × age)

### Female

BMR = 655.1 + (9.563 × weight) + (1.850 × height) − (4.676 × age)
